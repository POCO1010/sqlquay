# Distribution notes

SQLQuay source code and its bundled Python query policies are distributed under the MIT license in LICENSE.

Java, Python, Alibaba Cloud CLI and MySQL Connector/J are external prerequisites, not included in the VSIX. Obtain them from their official publishers and follow their licenses. In particular, the Connector/J driver remains user-supplied.

The VSIX does not contain Database Client binaries, decompiled code or resources. Documentation screenshots use synthetic Demo data.
